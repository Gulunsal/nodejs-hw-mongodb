# nodejs-hw-mongodb

Bu proje, Node.js ve MongoDB kullanarak oluşturulmuş bir contact yönetim API'sidir.

## Bağlantılar

- GitHub Repository: [https://github.com/gulayduzgun/nodejs-hw-mongodb](https://github.com/gulayduzgun/nodejs-hw-mongodb)
- Live API: [Render.com URL'niz buraya gelecek]

## Endpoints

- GET /contacts - Tüm contact'ları listeler
- GET /contacts/:id - Belirli bir contact'ı getirir

## Teknolojiler

- Node.js
- Express
- MongoDB
- Mongoose
